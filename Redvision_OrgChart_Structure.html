💻 Developer Implementation Guide
Redvision Organization Structure for HRMS:
  • 5 Distinct Hierarchy Levels: Management → Manager → TL → Executive → Intern
  • Approval Authority: Manager approves leaves and performance reviews; escalations go to Management
  • Leave Policy Integration: Different policies may apply based on hierarchy level (Probation: no leaves except emergency)
  • Department Structure: Each department has 1 Management, 2-3 Managers, 6-9 TLs, 15-25 Executives, 5-15 Interns
  • Reporting Chain: Clear chain of command for escalations and approvals
  • Performance Management: TL tracks attendance; Manager reviews performance; Management provides strategic feedback
  • Probation Handling: During 1-month probation, no leaves except emergency with LWP status

HRMS Database Requirements:
  • Employee Table Fields: hierarchy_level, reporting_manager_id, department_id, designation_type, probation_status, probation_end_date
  • Designation Mapping: Create designation table with hierarchy levels (Management=1, Manager=2, TL=3, Executive=4, Intern=5)
  • Leave Approval Flow: Executive → TL (for information) → Manager (approval) → HR (verification)
  • Escalation Rules: If TL unavailable, escalate to Manager; if Manager unavailable, escalate to Management
  • Appraisal Workflow: Executive & Intern reviewed by TL → Manager reviews → Management approval
  • Leave Balance Tracking: Track per employee; deduct during weekends if priority work required

Code of Conduct Integration:
  • Working Hours: 10:00 AM - 7:30 PM (Fixed)
  • Attendance: Biometric/HRMS Tool (15-minute grace period)
  • Late Comings: After 10:10 AM = Half Day deduction; After 11:00 AM = Full Half Day leave
  • Leave Entitlement: 15 Annual + 1 Birthday (prorated quarterly: Q1=3.5, Q2=3.5, Q3=3.5, Q4=4.5)
  • Leave Approval: Email to TL/Manager (CC HR) mandatory; no email = LOP
  • Penalties: Unapproved leave = double deduction; Unplanned leave = double pay; LWP = salary cut
💾 Sample Database Schema
-- Designation/Hierarchy Levels Table
CREATE TABLE designation (
  designation_id INT PRIMARY KEY,
  name VARCHAR(50), -- 'Management', 'Manager', 'TL', 'Executive', 'Intern'
  hierarchy_level INT, -- 1-5
  description TEXT
);

-- Employee Table
CREATE TABLE employee (
  employee_id INT PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(100),
  department_id INT,
  designation_id INT,
  reporting_manager_id INT, -- Foreign key to employee table
  hierarchy_level INT,
  joining_date DATE,
  probation_end_date DATE,
  probation_status BOOLEAN,
  FOREIGN KEY (reporting_manager_id) REFERENCES employee(employee_id)
);

-- Leave Policy Table (different policies per hierarchy)
CREATE TABLE leave_policy (
  policy_id INT PRIMARY KEY,
  hierarchy_level INT,
  annual_leave INT, -- 15 for confirmed, 0 for probation
  casual_leave INT,
  emergency_leave INT,
  birthday_leave INT
);
